# ParcelBoard App

一个用于 **Scripting App** 的 iPhone 主屏幕快递汇总组件。支持小号、中号和大号组件，可展示多件快递的承运商、当前状态、最近轨迹和更新时间，并通过组件按钮刷新。

## 安装

1. 将整个 `ParcelBoard App` 目录导入或复制到 Scripting App。
2. 在 Scripting 中运行一次“快递进度汇总 2”。
3. 选择“配置快递100 API”，输入快递100企业管理后台里的 `customer` 和 `key`。
4. 选择“添加快递”，依次填写快递公司、运单号和名称。
5. 长按 iPhone 主屏幕，添加 Scripting 小组件并选择“快递进度汇总 2”。

## 数据与隐私

- 查询使用快递100官方实时查询接口：`https://poll.kuaidi100.com/poll/query.do`。
- 查询时会把快递公司、运单号及你填写的可选手机号发送给快递100。
- `customer`、`key`、运单和缓存仅保存在当前脚本的私有 `Storage` 中，不写入源码。
- 顺丰和中通查询需要关联手机号；其他内置快递默认不收集手机号。
- 组件会执行 HTTPS `POST` 请求，不读取通讯录、定位、照片、日历或文件。

## 刷新规则

快递100要求同一运单的实时查询间隔至少 30 分钟。ParcelBoard 会缓存每次查询结果，并阻止缓存期内重复请求。iOS WidgetKit 决定组件的实际唤醒时间，因此刷新可能晚于计划时间。

## 内置快递

顺丰、中通、圆通、韵达、申通、极兔、京东、EMS、德邦、菜鸟速递和邮政包裹。

## 文件

- `index.tsx`：手机端管理菜单。
- `widget.tsx`：主屏幕组件。
- `app_intents.tsx`：组件刷新按钮。
- `kuaidi100.ts`：快递100官方接口适配器。
- `tracker.ts`：30 分钟缓存、刷新和失败回退。
- `storage.ts`：私有本地数据。
