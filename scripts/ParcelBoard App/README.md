# ParcelBoard App（快递短信）

一个只从剪贴板快递短信识别运单的 **Scripting App** 主屏幕组件，不需要快递100配置，也不会发送网络请求。

## 使用

1. 导入并运行“快递短信”。
2. 在短信 App 中复制快递通知全文。
3. 返回脚本，点击“从剪贴板导入快递短信”。
4. 添加 Scripting 主屏幕组件并选择“快递短信”。

重复导入同一运单会更新导入时间，不会创建重复记录。

## 数据与隐私

- 只读取你点击按钮时的剪贴板文本。
- 只在当前脚本的私有 `Storage` 中保存快递公司、运单号和导入时间。
- 不保存短信全文，不发送网络请求，不需要 API Key。

## 支持的快递

顺丰、中通、圆通、韵达、申通、极兔、京东、EMS、德邦、菜鸟速递和邮政包裹。
