# 快递取件码

自动提取快递短信中的取件码，并显示在 Scripting 主屏幕组件中。没有快递100、API Key、运单配置或网络请求。

## 为什么需要快捷指令

iOS 不向第三方 App 开放短信收件箱读取权限，因此不能在 Scripting 中弹出一个“短信授权”后直接扫描。可行且自动的系统方式是使用“快捷指令”的“收到信息”个人自动化，把新短信正文传给本脚本。

## 一次性设置

1. 导入并运行“快递取件码”。
2. 打开系统“快捷指令”→“自动化”→“新建自动化”→“信息”。
3. “信息包含”填写“码”，并选择“立即运行”。脚本会忽略普通验证码。
4. 添加 Scripting 的“Run Script”操作，选择“快递取件码”。
5. 将操作输入设为“快捷指令输入”中的“信息内容”。
6. 保存自动化，再添加 Scripting 主屏幕组件并选择“快递取件码”。

之后收到符合条件的短信时，快捷指令会自动运行脚本。脚本识别“取件码、取货码、提货码、领取码”等格式并刷新组件。

## 隐私

- 短信正文只由系统快捷指令传给本机 Scripting。
- 只保存取件码、识别出的快递名称和收到时间，不保存短信全文。
- 不发送网络请求。
